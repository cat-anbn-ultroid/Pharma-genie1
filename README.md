# Pharma Genie - Landing Page

**"Replacing legacy, one-size-fits-all medicine with a custom pharmacogenomic dosing engine that turns complex genetic variations into life-saving, precision prescriptions."**

This repository contains the static landing page for **Pharma Genie**, designed with a clean, industry-grade layout and a tailored "grey-green" color palette.

## Features
- **Responsive Design**: Built entirely with Tailwind CSS via CDN.
- **Animated Logo**: Smooth, CSS-based floating keyframe animation for the hero section logo.
- **Pitch Deck Integrated**: Key architecture points (Interpret, Reconcile, Context) and market statistics (4,600+ endogamous groups, 49% polypharmacy rate) are extracted straight from the concept deck.
- **Ready to Host**: 100% static HTML file, perfectly suited for zero-config deployments.

## Deployment on Render
This project is ready to be hosted as a **Static Site** on Render.

1. **Upload to GitHub**: 
   - Create a new repository on GitHub.
   - Upload `index.html`, this `README.md`, and your `logo.png` file to the root of the repository.
2. **Connect to Render**:
   - Go to your [Render Dashboard](https://dashboard.render.com).
   - Click **New** -> **Static Site**.
   - Connect the GitHub repository you just created.
3. **Configure Settings**:
   - **Build Command**: `Leave blank`
   - **Publish Directory**: `.` (the root directory)
4. **Deploy**: Click **Create Static Site**. Your landing page will be live instantly!

## Assets Note
Make sure the `logo.png` provided in your original materials is placed in the root directory alongside `index.html` so it renders correctly in both the navigation bar and the animated hero section.
